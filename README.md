# Loop on line 402 | for k in range(total): |
Before the loop starts (total) is defined as num_arms * step on line 401. So if you have 6 arms and 1 extra light between each, total is 12. There are 12 positions around the ring. Each time the loop runs k is the position number (0, 1, 2, 3,... up to 11). _fixture_position calculates where on the ring that position should be. Then it creates the parts for that position, after those parts are moved into place and parented to the group. Each time the position around the ring changes. Position 0 is at angle 0, position 1 is a bit further around, position 2 is further still, and so on until the circle is full. This loop repeats the same sequence of creating a dish, candle, and bulb happens at every position. The loop is what lets you write that code once and have it happen 6 times, 12 times, however many times you need.
